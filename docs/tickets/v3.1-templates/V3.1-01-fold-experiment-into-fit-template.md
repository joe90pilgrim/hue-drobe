## Scope
**Goal:** One clean fitter with the two proven techniques built in, the frozen options gone, and the experiment branch merged and closed.

**First, tidy the branch:**
- Commit the uncommitted experiment work on `feat/V3-14-cloth-layering-experiment` (the write-up, `run.py` and its README, `pack/experiments/v3-15/`, all modified after the last commit).
- Check `npm run check` passes on that branch, then merge it into `master`. It contains the V3-05, V3-07, V3-07a, V3-07b, V3-07c and V3-09 branches before it. Delete the merged feature branches locally.

**Then fold in:**
- `settle.rest: "template"`: the cloth's rest shape is the template's own mesh (dynamic-mesh rest-shape key, as in `cloth_fit()`), so the garment relaxes towards its designed shape instead of the skin-tight MHCLO fit.
- `settle.pin`: garment-side pin groups chosen on the template mesh (collar or top ring, shoulder seams, optional back band and cuffs), replacing `settle.pinned` (body groups) and `settle.pin_above_armpit_cm`.
- `hide_inner: true` (default for outer and mid layers with `inner_layers`): export the inner garment with the faces it covers removed, as `<name>_<inner>_under_<id>.glb`, and run the layer check against the inner layer as drawn. This replaces `inner_push` and the Shrinkwrap push-off against inner layers.
- **Remove** `loose`, `loose_fit`, `torso_bands`, `convex_hull`, `hull_radii`, `drape_envelope`, `smooth_up`, `hem_lower`, `split_by_gap`, `inner_push` and `pin_above_armpit_cm`, with their validation and tests. `validate_meta` rejects them with a clear message.
- Keep `keep_islands` (V3-07c): it selects part of a pack item, it doesn't reshape it.
- Retire the V3-09 blazer templates: delete `pack/templates/outer/blazer_suit3/` and `blazer_suit_f2/` (unapproved; the fronts swing open).

**Acceptance criteria:**
- The V3-14 shirt-over-tee case built through `fit_template.py` (not the experiment script) gives the experiment's numbers on `synthetic_female_large`: 0 layer pairs against the tee as drawn, 0 body pairs and 0 gap rays, within 0.1 cm.

- The shift dress report is unchanged.
- Two builds are byte-identical.
- Unit tests for the new and removed meta fields; `npm run check` passes on `master` after the merge.
- A short decision record in `docs/decisions/`.
