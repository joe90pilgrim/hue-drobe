# V1.1-02 Saved clothes library

**Ceiling:** 1 hour. The most this ticket may take, not a target. Stop as soon as the acceptance criteria are met.
**Worker:** Sonnet, low. Simple saving and listing, but it sets the data shape that outfits and later versions build on, so Sonnet rather than Haiku.
**Depends on:** MVP clothes and colour picker

## Goal
Save a garment in a colour as a named item, see your saved items in a library, and put any of them on the avatar.

## Scope
- A saved item is: garment template (tee, sweatshirt, trousers, shorts, and neckline once V1.1-04 lands), colour, name.
- Save the garment currently on the avatar as an item.
- A library screen listing saved items, with a colour swatch and name; rename and delete.
- Tapping an item puts it on the avatar.
- Design the stored record so a later version can add a photo, a profile owner and a source (for v2 and v4) without migrating it painfully: include a version number on the record.

## Decisions (made 15 Nov 2026, see `docs/decisions/2026-11-15-v1.1-02-saved-clothes-decisions.md`)
- Naming: auto-named from the colour and garment, editable.
- Navigation: a Wardrobe tab.

If a decision isn't made when this ticket starts, stop and ask rather than guess.

## Acceptance criteria
- Save, rename, delete and wear an item, and it survives a restart.
- End-to-end test saves an item and wears it.
- Joe's visual sign-off on the library screen.

## Status
Built; `npm run check` passes, including the end-to-end test that saves, renames, wears and deletes an item and reloads. Joe's visual sign-off on the library screen is pending, so the ticket stays open.
