# V1.1-03 Preset outfits

**Ceiling:** 1 hour. The most this ticket may take, not a target. Stop as soon as the acceptance criteria are met.
**Worker:** Haiku, high. Same pattern as the saved clothes library, one level up.
**Depends on:** V1.1-02

## Goal
Save combinations of items as named outfits and apply one in a single tap.

## Scope
- An outfit is: a name plus one saved item per slot (top, bottom).
- Save the current look as an outfit; list, rename, delete; apply in one tap.
- If an item in an outfit is deleted, the outfit shows that slot as empty rather than breaking.

## Decisions (made 15 Nov 2026, see `docs/decisions/2026-11-15-v1.1-03-preset-outfit-decisions.md`)
- Saved outfits only. Starter outfits are on the roadmap (idea 17) to consider later.
- Applying an outfit replaces everything on the avatar.

## Decisions as originally asked
- **What does 'preset' mean?** (a) outfits you save yourself, (b) starter outfits that come with the app, or (c) both. This ticket assumes (a). Starter outfits would need content from you.
- Should applying an outfit replace everything on the avatar, or only the slots the outfit fills? Recommendation: replace everything.

If a decision isn't made when this ticket starts, stop and ask rather than guess.

## Acceptance criteria
- Save, apply, rename and delete an outfit; it survives a restart.
- Deleting an item used in an outfit leaves the outfit working.
- Joe's visual sign-off.

## Status
Built: outfits save from the Dress screen, list, rename, delete and apply in the Wardrobe tab, and survive a reload. `npm run check` passes, including end-to-end tests for save, rename, wear, and a deleted item leaving its slot empty. Joe checked the Dress and Wardrobe screens on 15 Nov 2026 and confirmed they look right. Ticket closed.
