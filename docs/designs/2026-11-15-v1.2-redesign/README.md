# Version 1.2 redesign: agreed designs and developer brief (15 Nov 2026)

The redesign Joe agreed on 15 November 2026, phone first and then laptop (1280 × 800).

- `brief.md`: what to build. It ranks the issues, then describes the changes screen by screen, in seven pieces in build order. Each change is marked with the issues it fixes. Start here.
- `index.html`: every screen on one page. Open it in a browser.
- `00-map-of-screens.html`: the navigation, with room marked for version 2 and later.
- `phone-01` to `phone-10`: the phone screens (390 × 844).
- `desktop-01` to `desktop-08`: the laptop screens. These are fluid pages, designed at 1280 × 800.

Every screen opens on its own, and the tabs, rows and buttons link to the right screens. The colour chooser (`phone-03`, `desktop-02`) and the palette favourites (`phone-10`, `desktop-08`) work, so they can be tried by hand. The figure is a stand-in for the 3D avatar, and the clothes, outfits and True Winter result are sample content.

These are design files, not app code. They load Inter and Bricolage Grotesque from Google Fonts to preview. The app must self-host the fonts (see `brief.md`, B1). The editable originals are on the Claude design canvas "Hue-drobe redesign – phone", which also has a Desktop page.
