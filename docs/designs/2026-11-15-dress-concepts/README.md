# Dress the avatar: concept wireframes (15 Nov 2026)

Three medium-fidelity phone wireframes (390 × 844) for the main "dress the avatar" screen. Open any file in a browser to view it.

- `a-stage.html`: avatar as the hero, wardrobe in a bottom sheet. Best for trying things on; the score and inspiration shrink to chips.
- `b-outfit-rail.html`: slots down the side (layer, top, bottom, shoes) with the score explained against the season palette. Best for learning why an outfit works; smaller avatar.
- `c-colour-coach.html`: palette-led feed of suggested outfits, gap analysis and reference matches, with 3D on demand. Best for inspiration; depends on outfit generation (a later milestone).

Switching between Joe and Beth lives in the Me tab, so it isn't shown on these screens.

Garment names, scores and the Soft Autumn season are sample placeholders, not real results.

These are design notes only, not app code. The editable versions are on the Claude design canvas "Hue-drobe: Dress the avatar concepts".
