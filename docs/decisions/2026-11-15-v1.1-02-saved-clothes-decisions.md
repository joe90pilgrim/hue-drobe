# V1.1-02: saved items are auto-named, and the library is a Wardrobe tab

Date: 2026-11-15. Ticket: `docs/tickets/v1.1-make-it-mine/V1.1-02-saved-clothes.md`.

## Decision

- **Naming:** auto-named from colour and garment (for example 'Navy tee'), editable in the library. A blank name falls back to the auto name.
- **Navigation:** a Wardrobe tab in the bottom bar, as in all three concept designs.

## How it is stored

IndexedDB key `wardrobe`, a list of `{ v: 1, id, garment, colour, name, savedAt }`. `garment` is the pack name (`tee`, `sweatshirt`, `trousers`). `v` is the record version, so a later version can add a photo, an owner or a source and upgrade old records when loading. Saving the same garment in the same colour twice keeps one item. Wearing an item writes the stored outfit and colours, which the Dress screen reads when it opens.

The colour names come from a small hue and lightness rule, not a colour database, so they are approximate. That is why the name is editable.
