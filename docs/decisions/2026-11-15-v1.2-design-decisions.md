# Version 1.2 redesign: design decisions

**Date:** 15 November 2026
**Decided by:** Joe, with a design specialist (Claude)
**Brief and designs:** `docs/designs/2026-11-15-v1.2-redesign/`
**Tickets:** `docs/tickets/v1.2-redesign/` (V1.2-01 to V1.2-08)

## Decisions
- **Visual style.** Keep the overall look (calm, minimal, Inter, rounded cards). Change the colours to true neutrals with ink as the only accent, and add character with the name and logo, Bricolage Grotesque headings and black main buttons. No brand accent colour for now.
- **Colour accuracy comes first.** Nothing coloured in the interface touches the avatar stage or a swatch. The stage is neutral grey `#E3E3E3`. Chosen states are shown in ink, never with a tint.
- **Navigation.**
  - The tabs are Try on, Wardrobe and My colours. Imagine and Learn are themes of the app, not names on screen.
  - The phone has a top bar (name, logo, Menu) and a 56 px tab bar; the laptop has a 232 px sidebar.
  - Back up and restore moves to the Menu or the foot of the sidebar. That is also where the version 2 person switcher goes.
  - One tab slot stays free for later.
- **Try on.** The avatar is full width on the phone. What you're wearing is a list of rows built from the slots, so version 3's extra garments and layers each add a row. A piece is changed in a sheet (phone) or the side panel (laptop), never over the avatar.
- **Saving.** One named action for each kind: Favourite (a colour), Add to wardrobe (a garment in a colour), Save outfit.
- **Colour chooser.** A chooser built into the app replaces the browser's own, which on Android is a modal that covers the avatar. It has favourites, basics, Colour, Strength and Lightness sliders, and a colour code field.
- **Scope.** All 19 issues in the brief are in 1.2. UI and navigation only; no change to the data model, storage, quiz scoring, backup format or the viewer's colour maths.

## Moved to the roadmap

- Wardrobe search and more filters.
